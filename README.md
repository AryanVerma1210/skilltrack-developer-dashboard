# SkillTrack

A polished, local-first developer productivity dashboard built with **React + Vite**.

## Features
- Create, complete, filter, and delete learning goals
- Progress percentage and dashboard statistics
- LocalStorage persistence — data survives refreshes
- Responsive UI for desktop and mobile
- Clean component/state architecture with React hooks
- No backend or API key required

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Tech stack
- React 19
- Vite
- JavaScript (ES6+)
- Lucide React
- CSS
- Browser LocalStorage
